# California Housing Prices

Учебный проект по прогнозированию медианной стоимости жилья в районах Калифорнии. Я сравнил линейные модели, случайный лес и градиентный бустинг, чтобы понять, какие подходы лучше справляются с этой задачей.

Лучший результат на тестовой выборке показал **HistGradientBoostingRegressor**: R² — **0,857**, средняя абсолютная ошибка — **$28 939**.

## Данные

Для проекта используется датасет [California Housing Prices на Kaggle](https://www.kaggle.com/datasets/camnugent/california-housing-prices).

Целевая переменная — `median_house_value`, медианная стоимость жилья в районе. В качестве признаков используются географические координаты, медианный доход, возраст жилья, количество комнат, население, число домохозяйств и близость к океану.

Данные описывают **районы**, поэтому прогноз относится к медианной стоимости жилья в районе, а не к рыночной цене конкретного дома.

Перед обучением удаляются строки с некорректными сочетаниями признаков, например когда спален больше, чем комнат. Из исходных данных также создаются дополнительные признаки:

- количество комнат на домохозяйство;
- население на домохозяйство;
- доля спален среди комнат;
- отношение населения к числу комнат;
- произведение широты и долготы.

Числовые пропуски заполняются медианой, после чего признаки масштабируются. Категориальный признак `ocean_proximity` обрабатывается с помощью One-Hot Encoding. Все преобразования входят в pipeline вместе с моделью.

## Как проходило обучение

Данные разделены на обучающую и тестовую выборки в соотношении **80/20** с `random_state=42`. Для Ridge, Random Forest и HistGB параметры подбирались с помощью `RandomizedSearchCV` и трёхкратной кросс-валидации на обучающей выборке. Для обычной линейной регрессии использовались параметры по умолчанию.

Лучшая модель выбирается по среднему R² на кросс-валидации. Затем она оценивается на отложенной тестовой выборке.

## Результаты

| Модель | CV R² | Test R² | MAE | RMSE | MAPE |
|---|---:|---:|---:|---:|---:|
| Linear Regression | 0,524 | 0,654 | $49 606 | $68 786 | 28,47% |
| Ridge | 0,647 | 0,651 | $49 769 | $69 056 | 28,26% |
| Random Forest | 0,814 | 0,823 | $31 611 | $49 168 | 17,24% |
| **HistGB** | **0,842** | **0,857** | **$28 939** | **$44 216** | **15,74%** |

На этих данных ансамбли деревьев заметно обошли линейные модели. HistGB уменьшил MAE примерно на **$20 700** по сравнению с обычной линейной регрессией. Значения метрик относятся к конкретному разбиению и выбранным настройкам; они не гарантируют такую же точность на других данных.

## Что видно на графиках

На графике реальных и предсказанных значений большинство точек расположено вдоль линии идеального прогноза. При этом ошибки заметны по всему диапазону цен, а для дорогого жилья разброс особенно велик.

На графике остатков выделяется диагональная граница. Она связана с большим количеством значений целевой переменной около **$500 000**: верхняя граница цены в данных ограничивает то, чему модель может научиться для дорогих районов. Поэтому прогнозы у этой границы стоит интерпретировать осторожно.

На графике важности наиболее заметны широта, долгота и медианный доход. Это показывает, какую роль местоположение и характеристики района играют в работе модели. При этом важность признака сама по себе не доказывает причинную связь.

## Запуск

Для запуска нужны Python **3.12 или новее** и зависимости:

```bash
pip install numpy pandas scipy scikit-learn matplotlib seaborn joblib
```

Скачайте датасет по ссылке выше и поместите файл `housing.csv` в папку проекта. Затем запустите обучение:

```bash
python main.py
```

Скрипт обучит модели, выведет метрики и сохранит обученные pipeline в файлы `best_model.pkl` и `all_models.pkl`.

## Структура проекта

```text
├── data.py            # загрузка и очистка данных
├── features.py        # исходные и дополнительные признаки
├── pipelines.py       # предобработка и сборка pipeline
├── training.py        # обучение, подбор параметров и метрики
├── visualization.py   # графики результатов
├── predict.py         # работа с прогнозом
├── main.py            # запуск обучения и сохранение моделей
└── housing.csv        # исходные данные
```

## Ограничения

Это учебный проект на историческом датасете. Модель не учитывает текущее состояние рынка и не предназначена для оценки стоимости конкретной недвижимости. Ограничение целевой переменной около $500 000 и случайное разделение данных также влияют на интерпретацию результатов.

Для дальнейшей проверки полезно оценить модель на географически отделённых районах и отдельно изучить ошибки в разных ценовых диапазонах.
